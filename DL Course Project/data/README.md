# Dataset Directory

Place Kaggle's `city_day.csv` file directly inside this directory (`data/city_day.csv`).

### Download Instructions:
1. Visit the Kaggle dataset page:
   [Air Quality Data in India](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india)
2. Click **Download** to get the archive.
3. Extract `city_day.csv` and move it to this folder:
   `DL Course Project/data/city_day.csv`

### Expected Columns in `city_day.csv`:
- `City`: City name (e.g., Delhi, Mumbai, Bengaluru, etc.)
- `Date`: Date in `YYYY-MM-DD` format
- `PM2.5`: Particulate matter 2.5 concentration
- `AQI`: Air Quality Index
- Other air pollutants (`PM10`, `NO2`, `CO`, `SO2`, `O3`, etc.)
